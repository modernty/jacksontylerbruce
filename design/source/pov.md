# Point of view: AI product design (Nov 19 2026)

Status: approved Nov 19 2026. Every project summary, case study and
chat answer draws from these principles. Each one is stated plainly, in the studio voice (no
subject, no hype), and is backed by work on the site. A principle with no work behind it
doesn't belong here.

## Positioning line
Designer leading AI products from first principle to shipped detail. Agents people trust,
for health, finance, support and the public sector.

## Principles

### 1. Earn the right to remember.
An assistant should be useful enough to feel like it knows you, and restrained enough that
it never feels like it's watching. A memory needs a moment of asking, a moment of review, a
date it expires, and a way to be forgotten for good. Without those, memory is surveillance
with good manners.
- Proof: PC Chat memory study (12 labs, four tensions: forgetful/presumptuous,
  cold/creepy, interruptive/buried, black box/overexplained). Remedy, Memory and Chat History.

### 2. Be useful before you ask.
In the agentic era, tools become relationships, and a relationship starts with a favour. An
agent earns trust by doing real work before it asks for any. Read the tickets first, then ask
for setup. Its first message carries a real number, not a greeting. Small wins add up to the
relationship, and each one is credited to the agent that earned it.
- Proof: Botpress, the trusted helpdesk (Lily reads last month's tickets and proposes the first
  skill; every small win is credited to Lily). Remedy Rx golden path: one request, two outcomes,
  resolved in one conversation.

### 3. Conversation is a surface, not the product.
Chat is one door among many. A refill belongs on the lock screen. An allergy belongs in the
cart. An invoice belongs where the work already happens. The interface steps back and the
outcome stays.
- Proof: Intuit (invoice, payment and wallet inside ChatGPT, one link out). PC Chat "Leave the
  chat" lab.

### 4. Show the working, then earn the autonomy.
Trust in AI is built from reasoning a person can check: sources, provenance, a reason at
every level. Regulated industries refuse the black box, and they are right to. Autonomy
follows the evidence. Nobody hands over a whole operation on day one. An agent drafts for
approval first, its approval rate is measured, and it is given more one skill and one limit at
a time. The person stays in charge.
- Proof: Lazarus (brand, Model Playground, Talent Management, Whitelist). Botpress trust ladder
  (helps you set up → drafts for approval → acts on its own → runs the desk; "seeing 18 of 20";
  refunds under $50 first). Remedy citations and "memory used" sources.

### 5. One voice, contextual credentials.
An agent should feel like one relationship, however many systems sit behind it. The voice
stays the same. The authority changes with the moment: a pharmacist's sign-off, a bank's
confirmation.
- Proof: PC One unified agent (one name, one context, never multi-agent). Lily at two sizes,
  identical everywhere.

### 6. The handoff is part of the design.
Design that can't be built as intended isn't finished. Design and strategy travel together,
and the spec is a product of its own: data-driven, reviewable, hard to misread.
- Proof: Remedy, the work. The Loblaw handoff site (screens, system, behaviour rules, demo mode).
