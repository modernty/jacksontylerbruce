Memory

The whole set, grouped: seven groups and thirty-two memories under a summary of what the assistant has been told.

Selecting

Select turns every row into a choice: a checkbox at the left, Select all and Cancel in the bar, and a Delete that counts what is ticked.

Viewing a memory

One memory as a pushed page — its category, the memory, when it changed, where it came from, and the fields it is made of.

Editing a memory

One field at a time, in a sheet over the page, with the keyboard up and the required caption under the input.

Deleting a memory

The confirmation, naming the consequence: the detail can be saved again, and chat history is untouched.

After deletion

The list afterwards, with a toast naming what happened. A memory drawn in two groups leaves both.
